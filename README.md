# Sky Hop Legends

A 3D obby party game for phones: race bots and friends across 12 maps, survive party games and win the Legends Cup.

- **Play in the browser:** https://fumvexa-oss.github.io/sky-hop-legends/
- **Android app:** https://github.com/fumvexa-oss/sky-hop-legends/releases/latest/download/SkyHopLegends.apk

## How this repository works
- `index.html` is the whole game. GitHub Pages hosts it for free.
- **Android app** workflow builds a signed APK on every game update and puts it in Releases.
- **Real 3D screenshots** workflow plays every map in a real browser and saves screenshots.
- **Make app icons** workflow draws the app icons from `tools/icon.html`.
